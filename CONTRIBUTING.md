# Contributing to Declarative Charts

Thank you for your interest in this project!

**We are not yet accepting contributions.** The library is in active development toward a 1.0 release, and the API may change significantly.

## Reporting Issues

If you find a bug or have a feature request, please open an issue on GitHub. We appreciate your feedback!

## Future Contributions

Once we reach a stable release, we plan to open up contributions. Check back later or watch the repository for updates.
