Bar Sizing & Spacing

Control bar widths and spacing between bars in bar charts

Bar Width

Each bar can have its own width specified in pixels, rems, ems, or unitless numbers. Use width on individual bars, bar-width on groups, or bar-width on the chart.

Width Cascade

Bar width follows a cascade: individual bar width > group bar-width > chart bar-width.

Group-Level Width Control

<dc-chart width="500" height="350">
  <dc-title>Group-Level Width Control</dc-title>
  <dc-bar-group label="Narrow Group" bar-width="30px">
    <dc-bar value="45" label="Product A" fill="#2196F3"></dc-bar>
    <dc-bar value="38" label="Product B" fill="#4CAF50"></dc-bar>
    <dc-bar value="52" label="Product C" fill="#FF9800"></dc-bar>
  </dc-bar-group>
  <dc-bar-group label="Wide Group" bar-width="80px">
    <dc-bar value="55" label="Product A" fill="#2196F3"></dc-bar>
    <dc-bar value="42" label="Product B" fill="#4CAF50"></dc-bar>
    <dc-bar value="48" label="Product C" fill="#FF9800"></dc-bar>
  </dc-bar-group>
</dc-chart>
Group-Level Width Control

Cascade Override Example

<dc-chart width="500" height="350" bar-width="50px">
  <dc-title>Width Cascade Example</dc-title>
  <!-- Uses chart default (50px) -->
  <dc-bar value="30" label="Default" fill="#E91E63"></dc-bar>
  <!-- Group overrides chart default -->
  <dc-bar-group label="Group Override" bar-width="30px">
    <dc-bar value="45" label="A" fill="#2196F3"></dc-bar>
    <!-- Individual bar overrides group and chart -->
    <dc-bar value="38" label="B" fill="#4CAF50" bar-width="80px"></dc-bar>
    <dc-bar value="52" label="C" fill="#FF9800"></dc-bar>
  </dc-bar-group>
  <!-- Individual bar overrides chart default -->
  <dc-bar value="50" label="Override" fill="#9C27B0" bar-width="100px"></dc-bar>
</dc-chart>

Gutter Spacing

By default, bars and groups have 10px spacing between them. Use the gutter attribute to customize spacing.

Group Gutter

Groups have spacing between them, but bars within groups touch by default. Each group can override the chart's gutter with its own gutter attribute.

Default Group Spacing

<dc-chart width="500" height="350" gutter="10">
