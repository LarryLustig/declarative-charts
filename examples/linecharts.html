Basic Line Chart

Lines can contain multiple series. Use line-color on the chart as a default, or specify individual colors per line:

Multi-Line Chart

<dc-line-chart width="600" height="400" stroke-colors="#9C27B0">
  <dc-title>Temperature Trend</dc-title>
  <dc-line label="City A">
    <dc-point value="15" label="Mon"></dc-point>
    <dc-point value="18" label="Tue"></dc-point>
    <dc-point value="22" label="Wed"></dc-point>
    <dc-point value="20" label="Thu"></dc-point>
    <dc-point value="25" label="Fri"></dc-point>
  </dc-line>
  <dc-line color="#FF5722" label="City B">
    <dc-point value="12" label="Mon"></dc-point>
    <dc-point value="16" label="Tue"></dc-point>
    <dc-point value="19" label="Wed"></dc-point>
    <dc-point value="23" label="Thu"></dc-point>
    <dc-point value="21" label="Fri"></dc-point>
  </dc-line>
</dc-line-chart>
Temperature Trend

Per-Point Colors

Individual points can have their own colors, overriding the line's default color:

Temperature with Alerts

<dc-line-chart width="700" height="350">
  <dc-title>Temperature with Alerts</dc-title>
  <dc-line color="#4CAF50" label="Temperature">
    <dc-point value="18" label="Mon"></dc-point>
    <dc-point value="22" label="Tue"></dc-point>
    <dc-point value="35" label="Wed" color="#FF5722"></dc-point>
    <dc-point value="20" label="Thu"></dc-point>
    <dc-point value="19" label="Fri"></dc-point>
    <dc-point value="38" label="Sat" color="#FF5722"></dc-point>
    <dc-point value="21" label="Sun"></dc-point>
  </dc-line>
</dc-line-chart>
Temperature with Alerts - Red Points Exceed Safe Limits

Custom Border Styling

Use the standard style attribute to customize the chart border:

Styled Line Chart

<dc-line-chart width="700" height="400" stroke-colors="#FF5722"
               style="border: 4px solid #FF5722; border-radius: 15px">
  <dc-title>Styled Line Chart with Custom Border</dc-title>
  <dc-line label="Revenue">
    <dc-point value="10" label="Jan"></dc-point>
    <dc-point value="15" label="Feb"></dc-point>
    <dc-point value="25" label="Mar"></dc-point>
    <dc-point value="35" label="Apr"></dc-point>
    <dc-point value="30" label="May"></dc-point>
  </dc-line>
</dc-line-chart>

Point Shapes

Customize point shapes at chart, line, or individual point level. Supports common shapes and unicode characters:

Custom Point Shapes

<dc-line-chart width="700" height="400">
  <dc-title>Product Performance with Custom Shapes</dc-title>
  <dc-line color="#E91E63" label="Product A" point-shape="square">
    <dc-point value="10" label="Q1"></dc-point>
    <dc-point value="15" label="Q2"></dc-point>
    <dc-point value="25" label="Q3"></dc-point>
    <dc-point value="35" label="Q4"></dc-point>
  </dc-line>
  <dc-line color="#9C27B0" label="Product B">
    <dc-point value="20" label="Q1" shape="circle"></dc-point>
    <dc-point value="22" label="Q2" shape="triangle"></dc-point>
    <dc-point value="30" label="Q3" shape="diamond"></dc-point>
    <dc-point value="28" label="Q4" shape="star"></dc-point>
  </dc-line>
  <dc-line color="#3F51B5" label="Product C" point-shape="★">
    <dc-point value="5" label="Q1"></dc-point>
    <dc-point value="12" label="Q2" shape="♦"></dc-point>
    <dc-point value="18" label="Q3"></dc-point>
    <dc-point value="24" label="Q4" shape="●"></dc-point>
  </dc-line>
</dc-line-chart>
