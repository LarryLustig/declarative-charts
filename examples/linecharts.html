Basic Line Charts

Line charts display data points connected by lines. Use <dc-line> elements containing <dc-point> elements. Multiple lines can be displayed on the same chart, each with its own color.

Curve Fitting

Control how lines connect points using the curve-fit attribute. Set at the chart level for all lines, or per-line for individual control:

  • linear (default) - Straight line segments between points
  • smooth - Catmull-Rom spline that curves smoothly through all points
  • monotone - Monotonic interpolation that never overshoots between points
  • step - Step function (horizontal then vertical) for discrete value changes
