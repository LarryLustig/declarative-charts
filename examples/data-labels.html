Data Labels

Control the display of labels, values, and percentages on chart elements with show-label, show-value, and show-percent attributes.

Attribute Values: The show-* attributes accept:
  • true or present without value - always show
  • false - never show
  • 5% - show only when element's percentage >= 5%
  • 100 - show only when element's value >= 100

Basic Boolean Values

Use true or false to control visibility of labels, values, and percentages.

Using Pop-Ups Instead

When slices are too small to display labels clearly, you can use pop-ups to show information on hover instead.

All Labels via Pop-Ups

    show-label="false" show-percent="false">
  <dc-title>Hover for Details</dc-title>
  <dc-pie-slice value="45" label="Desktop" fill="#4ECDC4">
    <dc-popup trigger="hover">

      45 users (45%)
    </dc-popup>
  </dc-pie-slice>
