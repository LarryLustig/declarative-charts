Default Configuration

The <dc-defaults> element sets default attributes for charts, reducing repetition and enabling consistent styling

Page-Wide Defaults

Place a <dc-defaults> element at the top of your page to configure all charts. All charts below inherit animations and the viridis palette.

Bar Chart

<dc-defaults animations palette="viridis"></dc-defaults>

<dc-chart width="500" height="350">
  <dc-title>Quarterly Revenue</dc-title>
  <dc-bar value="45" label="Q1"></dc-bar>
  <dc-bar value="72" label="Q2"></dc-bar>
  <dc-bar value="58" label="Q3"></dc-bar>
  <dc-bar value="91" label="Q4"></dc-bar>
</dc-chart>
Quarterly Revenue

Pie Chart

<!-- Same dc-defaults applies -->

<dc-pie-chart width="500" height="350">
  <dc-title>Market Share</dc-title>
  <dc-pie-slice value="45" label="Desktop"></dc-pie-slice>
  <dc-pie-slice value="35" label="Mobile"></dc-pie-slice>
  <dc-pie-slice value="20" label="Tablet"></dc-pie-slice>
</dc-pie-chart>
Market Share

Scoped Defaults

Defaults can be scoped to specific containers. Charts inside a container use the nearest <dc-defaults>.

Using Outer Defaults

<dc-defaults palette="category10"></dc-defaults>

<dc-chart width="500" height="350">
  <dc-title>Category10 Palette</dc-title>
  <dc-bar value="85" label="Sales"></dc-bar>
  <dc-bar value="65" label="Marketing"></dc-bar>
  <dc-bar value="45" label="Support"></dc-bar>
</dc-chart>
Category10 Palette

Scoped to Container

<div class="high-contrast-section">
  <dc-defaults high-contrast></dc-defaults>

  <dc-chart width="500" height="350">
    <dc-title>High Contrast Mode</dc-title>
    <dc-bar value="85" label="Sales"></dc-bar>
    <dc-bar value="65" label="Marketing"></dc-bar>
    <dc-bar value="45" label="Support"></dc-bar>
  </dc-chart>
</div>

Overriding Defaults

Explicit attributes on a chart always override defaults.

Using Defaults

<dc-defaults palette="warm" animations></dc-defaults>

<!-- Uses warm palette and animations -->
<dc-chart width="500" height="350">
  <dc-title>Warm Palette (Default)</dc-title>
  <dc-bar value="80" label="A"></dc-bar>
  <dc-bar value="60" label="B"></dc-bar>
  <dc-bar value="90" label="C"></dc-bar>
</dc-chart>
Warm Palette (Default)

Overriding Palette

<!-- Overrides palette but keeps animations -->
<dc-chart palette="cool" width="500" height="350">
  <dc-title>Cool Palette (Override)</dc-title>
  <dc-bar value="80" label="A"></dc-bar>
  <dc-bar value="60" label="B"></dc-bar>
  <dc-bar value="90" label="C"></dc-bar>
</dc-chart>
Cool Palette (Override)

Formatting Defaults

Set consistent number formatting across all charts.

Currency Format

<dc-defaults value-format="currency USD" show-percent></dc-defaults>

<dc-chart width="500" height="350">
  <dc-title>Revenue by Region</dc-title>
  <dc-bar value="1500000" label="North"></dc-bar>
  <dc-bar value="1200000" label="South"></dc-bar>
  <dc-bar value="900000" label="East"></dc-bar>
  <dc-bar value="600000" label="West"></dc-bar>
</dc-chart>
Revenue by Region

Multiple Defaults

Combine multiple settings in a single <dc-defaults> element.

Combined Settings

<dc-defaults
    palette="category10"
    animations="500ms"
    auto-popup
    value-format="compact 1"
    show-value>
</dc-defaults>

<dc-chart width="500" height="350">
  <dc-title>Sales Overview</dc-title>
  <dc-bar value="4500000" label="Q1"></dc-bar>
  <dc-bar value="5200000" label="Q2"></dc-bar>
  <dc-bar value="4800000" label="Q3"></dc-bar>
  <dc-bar value="6100000" label="Q4"></dc-bar>
</dc-chart>
Sales Overview
