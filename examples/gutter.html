Basic Gutter Control

By default, bars and groups have 10px spacing between them. Use the gutter attribute to customize.

Per-Group Gutter Control

Each group can override the chart's gutter with its own gutter attribute.

Mixed Group Spacing

<dc-chart width="500" height="350" gutter="10">
  <dc-title>Mixed Group Spacing</dc-title>
  <!-- Uses chart default (10px) -->
  <dc-bar-group label="Default">
    <dc-bar value="45" label="A" color="#2196F3"></dc-bar>
    <dc-bar value="38" label="B" color="#4CAF50"></dc-bar>
  </dc-bar-group>
  <!-- Overrides with 40px gutter -->
  <dc-bar-group label="Wide" gutter="40">
    <dc-bar value="55" label="A" color="#E91E63"></dc-bar>
    <dc-bar value="42" label="B" color="#9C27B0"></dc-bar>
  </dc-bar-group>
  <!-- Overrides with 0px gutter -->
  <dc-bar-group label="Tight" gutter="0">
    <dc-bar value="62" label="A" color="#FF9800"></dc-bar>
    <dc-bar value="50" label="B" color="#795548"></dc-bar>
  </dc-bar-group>
</dc-chart>
