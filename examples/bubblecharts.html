Basic Bubble Charts

Bubble charts use <dc-bubble> elements with value for vertical position and size-value for bubble size. Labels appear on the category axis.

Simple Bubbles

<dc-chart width="500" height="350">
  <dc-title>Project Metrics</dc-title>
  <dc-bubble value="75" size-value="40" label="Alpha"></dc-bubble>
  <dc-bubble value="50" size-value="80" label="Beta"></dc-bubble>
  <dc-bubble value="90" size-value="25" label="Gamma"></dc-bubble>
  <dc-bubble value="35" size-value="60" label="Delta"></dc-bubble>
</dc-chart>
Project Metrics

Bubble Size Scaling

The size-value attribute determines bubble area (not radius), ensuring accurate visual comparison. Larger values create proportionally larger bubbles.

Varying Sizes

<dc-chart width="500" height="350">
  <dc-title>Revenue by Product</dc-title>
  <dc-bubble value="70" size-value="100" label="Product A" fill="#3b82f6"></dc-bubble>
  <dc-bubble value="55" size-value="50" label="Product B" fill="#3b82f6"></dc-bubble>
  <dc-bubble value="85" size-value="25" label="Product C" fill="#3b82f6"></dc-bubble>
  <dc-bubble value="40" size-value="75" label="Product D" fill="#3b82f6"></dc-bubble>
  <dc-bubble value="65" size-value="10" label="Product E" fill="#3b82f6"></dc-bubble>
</dc-chart>
Revenue by Product

Negative Values

Bubble charts support negative values on the y-axis. The zero line appears when the range spans both positive and negative values.

Mixed Positive and Negative

<dc-chart width="500" height="350">
  <dc-title>Profit/Loss by Region</dc-title>
  <dc-bubble value="45" size-value="60" label="North"
    fill="#4CAF50"></dc-bubble>
  <dc-bubble value="-20" size-value="40" label="South"
    fill="#F44336"></dc-bubble>
  <dc-bubble value="30" size-value="50" label="East"
    fill="#4CAF50"></dc-bubble>
  <dc-bubble value="-35" size-value="70" label="West"
    fill="#F44336"></dc-bubble>
</dc-chart>
Profit/Loss by Region

Palette-Based Coloring

Use palettes with value ranges to automatically color bubbles based on their value:

<dc-palette id="bubble-profit-loss">
  <dc-fill max-value="0" fill="#EF5350"></dc-fill>
  <dc-fill min-value="0" fill="#66BB6A"></dc-fill>
</dc-palette>
<dc-chart palette="bubble-profit-loss" width="500" height="350">
  <dc-title>Quarterly Performance</dc-title>
  <dc-bubble value="25" size-value="50" label="Q1"></dc-bubble>
  <dc-bubble value="-15" size-value="35" label="Q2"></dc-bubble>
  <dc-bubble value="40" size-value="65" label="Q3"></dc-bubble>
  <dc-bubble value="-5" size-value="25" label="Q4"></dc-bubble>
</dc-chart>
