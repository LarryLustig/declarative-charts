Group-Level Bar Width

Set width for all bars in a group using the bar-width attribute on dc-bar-group.

Group-Level Width Control

<dc-chart width="500" height="350">
  <dc-title>Group-Level Width Control</dc-title>
  <dc-bar-group label="Narrow Group" bar-width="30px">
    <dc-bar value="45" label="Product A" color="#2196F3"></dc-bar>
    <dc-bar value="38" label="Product B" color="#4CAF50"></dc-bar>
    <dc-bar value="52" label="Product C" color="#FF9800"></dc-bar>
  </dc-bar-group>
  <dc-bar-group label="Wide Group" bar-width="80px">
    <dc-bar value="55" label="Product A" color="#2196F3"></dc-bar>
    <dc-bar value="42" label="Product B" color="#4CAF50"></dc-bar>
    <dc-bar value="48" label="Product C" color="#FF9800"></dc-bar>
  </dc-bar-group>
</dc-chart>

Chart-Level Bar Width

Set a default width for all bars using the bar-width attribute on dc-chart.

Cascading Width Control

Bar width follows a cascade: individual bar width > group bar-width > chart bar-width.

Width Cascade Example

<dc-chart width="500" height="350" bar-width="50px">
  <dc-title>Width Cascade Example</dc-title>
  <!-- Uses chart default (50px) -->
  <dc-bar value="30" label="Default" color="#E91E63"></dc-bar>
  <!-- Group overrides chart default -->
  <dc-bar-group label="Group Override" bar-width="30px">
    <dc-bar value="45" label="A" color="#2196F3"></dc-bar>
    <!-- Individual bar overrides group and chart -->
    <dc-bar value="38" label="B" color="#4CAF50" width="80px"></dc-bar>
    <dc-bar value="52" label="C" color="#FF9800"></dc-bar>
  </dc-bar-group>
  <!-- Individual bar overrides chart default -->
  <dc-bar value="50" label="Override" color="#9C27B0" width="100px"></dc-bar>
</dc-chart>
