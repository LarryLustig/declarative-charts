Custom Border Styling

Use the standard style attribute to customize the chart border. You can combine border with border-radius, box-shadow, and other CSS properties:

No Border

<dc-chart width="450" height="300"
              style="border: none">
  <dc-title>No Border</dc-title>
  <dc-bar value="30" color="#4CAF50" label="A"></dc-bar>
  <dc-bar value="45" color="#8BC34A" label="B"></dc-bar>
  <dc-bar value="25" color="#CDDC39" label="C"></dc-bar>
</dc-chart>
No Border

Dashed Border

<dc-chart width="450" height="300"
              style="border: 5px dashed #9C27B0">
  <dc-title>Custom Border Example</dc-title>
  <dc-bar value="30" color="#E91E63" label="A"></dc-bar>
  <dc-bar value="45" color="#9C27B0" label="B"></dc-bar>
  <dc-bar value="25" color="#3F51B5" label="C"></dc-bar>
</dc-chart>
Custom Border Example

Rounded Border with Shadow

<dc-chart width="450" height="300"
              style="border: 3px solid #FF5722;
                     border-radius: 20px;
                     box-shadow: 0 6px 20px rgba(0,0,0,0.2)">
  <dc-title>Styled Chart</dc-title>
  <dc-bar value="45" color="#E91E63" label="Product A"></dc-bar>
  <dc-bar value="60" color="#9C27B0" label="Product B"></dc-bar>
  <dc-bar value="30" color="#3F51B5" label="Product C"></dc-bar>
</dc-chart>

Chart Padding

All charts have a default padding of 12% on all sides, which provides space for axes, labels, and titles. Padding follows CSS conventions:

  • Pixels (CSS default): padding="60" or padding="60px" - unitless values are treated as pixels
  • Percentages: padding="12%" - percentage of chart dimensions (recommended for responsive layouts)

Pixel values are converted to percentages based on chart dimensions. You can customize padding using CSS-style shorthand or individual properties:

  • padding - Shorthand (1-4 values like CSS: all | top/bottom left/right | top left/right bottom | top right bottom left)
  • padding-top, padding-right, padding-bottom, padding-left - Individual overrides

Default Padding (12% all sides)

<dc-chart width="450" height="300">
  <dc-title>Default Padding</dc-title>
  <dc-bar value="10" color="#FF6B6B" label="A"></dc-bar>
  <dc-bar value="25" color="#4ECDC4" label="B"></dc-bar>
  <dc-bar value="15" color="#45B7D1" label="C"></dc-bar>
</dc-chart>
Default Padding

No Padding (No Title)

Remove all padding to maximize chart area. Note: without padding, axes and labels may be clipped.

<dc-chart width="450" height="300" padding="0">
  <dc-bar value="10" color="#FF6B6B" label="A"></dc-bar>
  <dc-bar value="25" color="#4ECDC4" label="B"></dc-bar>
  <dc-bar value="15" color="#45B7D1" label="C"></dc-bar>
</dc-chart>

Minimal Side Padding with Title

Keep top padding for title, reduce left/right/bottom to 5 pixels:

<dc-chart width="450" height="300"
              padding-left="5"
              padding-right="5"
              padding-bottom="5">
  <dc-title>Minimal Sides</dc-title>
  <dc-bar value="10" color="#FF6B6B" label="A"></dc-bar>
  <dc-bar value="25" color="#4ECDC4" label="B"></dc-bar>
  <dc-bar value="15" color="#45B7D1" label="C"></dc-bar>
</dc-chart>
Minimal Sides

Increased Right Padding for Legend

When adding a legend on the right, increase right padding to prevent overlap:

<dc-chart width="450" height="300" padding-right="100">
  <dc-title>With Legend Space</dc-title>
  <dc-bar value="10" color="#FF6B6B" label="A"></dc-bar>
  <dc-bar value="25" color="#4ECDC4" label="B"></dc-bar>
  <dc-bar value="15" color="#45B7D1" label="C"></dc-bar>
  <dc-legend position="right"></dc-legend>
</dc-chart>
With Legend Space

Padding with Percentage

Use % suffix for percentage-based padding (recommended for responsive layouts):

<dc-chart width="450" height="300" padding="12%">
  <dc-title>12% Padding</dc-title>
  <dc-bar value="10" color="#FF6B6B" label="A"></dc-bar>
  <dc-bar value="25" color="#4ECDC4" label="B"></dc-bar>
  <dc-bar value="15" color="#45B7D1" label="C"></dc-bar>
</dc-chart>
