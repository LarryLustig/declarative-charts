Donut Charts

Pie charts with a hollow center, created using the inner-radius attribute

Basic Donut Chart

Use inner-radius to create a donut chart. The value is a percentage (0-100) of the outer radius:

Budget Allocation

<dc-pie-chart width="600" height="400" inner-radius="50">
  <dc-title>Budget Allocation</dc-title>
  <dc-pie-slice value="40" label="Development"></dc-pie-slice>
  <dc-pie-slice value="25" label="Marketing"></dc-pie-slice>
  <dc-pie-slice value="20" label="Operations"></dc-pie-slice>
  <dc-pie-slice value="15" label="Research"></dc-pie-slice>
</dc-pie-chart>

Donuts with Legends

Add a legend to identify slices, especially useful when labels don't fit on thin rings:

  <dc-legend position="right"></dc-legend>
