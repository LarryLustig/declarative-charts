Reference Lines & Bands

Targets, thresholds, budgets and SLAs drawn across the plot

Lines and Bands

One element covers both shapes an annotation takes, because they are the same idea at different widths. value draws a line; min and max draw a band between them.

A Target Line

<dc-chart width="500" height="350" value-format="number 0">
  <dc-reference value="100" label="Target"></dc-reference>
  <dc-bar value="95" label="Q1"></dc-bar>
  <dc-bar value="112" label="Q2"></dc-bar>
  <dc-bar value="74" label="Q3"></dc-bar>
  <dc-bar value="131" label="Q4"></dc-bar>
</dc-chart>

An Acceptable Band

<dc-reference min="80" max="120"
              fill="#16a34a"
              label="Acceptable"></dc-reference>
<!-- same bars -->

Bands are drawn beneath the data and lines above it. A band is a region of the plot, so whatever it overlaps has to stay readable; a line is a mark on the plot, and a target hidden behind a bar is no target at all.

Half-Open Bands

Either bound alone shades everything beyond it. That is how a danger zone is usually stated — “anything over 90” — and it should not need a maximum nobody has in mind.

Everything Above

<dc-reference min="90" fill="#dc2626"
              label="Over budget"></dc-reference>

Everything Below

<dc-reference max="50" fill="#ea580c"
              label="Under target"></dc-reference>

A Band and Its Target Together

Setting value alongside min and max is not a conflict. It draws the band's centre line, which is exactly what “acceptable range, target 100” means — one statement, one element.

Range Plus Centre

<dc-reference min="80" max="120" value="100"
              fill="#16a34a" stroke="#16a34a"
              label="Target"></dc-reference>

Several Annotations

<dc-reference min="80" max="120" fill="#16a34a"
              label="Acceptable"></dc-reference>
<dc-reference value="140" stroke="#dc2626"
              label="Limit"></dc-reference>
<dc-reference value="100" stroke="#2563eb"
              label="Target"
              label-position="start"></dc-reference>

label-position="start" moves a label to the left-hand end, which is the way to stop two of them landing on top of each other.

Styling

Lines are dashed red by default: dashed because a solid line the same weight as a data line reads as data, and red because the overwhelming majority of these are a limit someone is trying not to cross. fill falls back to stroke, so one colour attribute usually does.

Line Style

<dc-reference value="120" stroke="#7c3aed"
              stroke-width="3"
              stroke-dasharray="dotted"
              label="Stretch"></dc-reference>
<dc-reference value="60" stroke="#0891b2"
              stroke-dasharray="solid"
              label="Floor"></dc-reference>

On a Line Chart

<dc-chart width="500" height="350">
  <dc-reference min="0" max="40" fill="#dc2626"
                label="Critical"></dc-reference>
  <dc-line label="Uptime">...</dc-line>
</dc-chart>

Horizontal Charts

A reference is positioned on the value axis, wherever that axis happens to be. On a horizontal chart the line is drawn vertically and the band as a vertical stripe — the markup does not change.

Same Markup, Rotated

<dc-chart width="500" height="350"
          orientation="horizontal">
  <dc-reference min="90" fill="#dc2626"
                label="Over budget"></dc-reference>
  <dc-reference value="60" stroke="#2563eb"
                label="Target"></dc-reference>
  <dc-bar value="45" label="Alpha"></dc-bar>
  ...
</dc-chart>

On a Scatter Plot

<dc-chart width="500" height="350">
  <dc-reference value="40" label="Spec limit"></dc-reference>
  <dc-scatter label="Readings">...</dc-scatter>
</dc-chart>

How It Works

An annotation is not data

A reference is not focusable, contributes nothing to any total or percentage, and does not appear in the legend — its label is drawn on the line itself, so a legend entry would only repeat it. A chart holding nothing but references still shows the empty state: there is nothing for the annotation to be about.

It does widen an automatic axis

A target the axis crops off is worse than no target, because the chart looks complete and quietly omits the thing it was annotated with. Where the axis is bounded outright with min-value and max-value, the two kinds part company: a band that runs past the edge is clamped, because part of the region really is on screen and drawing that part is honest; a line outside the range is dropped and reported as DC114, because clamping it would place it somewhere it is not and the reader has no way to tell.

Screen readers get the comparison

The first reference that draws a line becomes the target the chart description compares the bars against — “all exceed target”, “target met in Q1, Q3”. A band alone is not a target: “between 80 and 120” has no single number to be above or below.

Styling from CSS

Three parts are exposed: ::part(reference-line), ::part(reference-band) and ::part(reference-label).
