Scatter Plots

Unconnected points positioned by two numbers, for showing how one variable moves with another

Basic Scatter Plot

Group points into a <dc-scatter> series and give each <dc-point> an x alongside its value. The x-axis becomes numeric on its own — no type="value" needed, because an x quietly ignored for want of a second attribute is exactly the failure this library tries not to have.

One Series

<dc-chart width="500" height="350">
  <dc-scatter label="Readings" fill="#2563eb">
    <dc-point x="5" value="12"></dc-point>
    <dc-point x="12" value="19"></dc-point>
    <dc-point x="18" value="31"></dc-point>
    <dc-point x="26" value="28"></dc-point>
    <dc-point x="34" value="46"></dc-point>
    <dc-point x="41" value="52"></dc-point>
  </dc-scatter>
</dc-chart>

Comparing Two Groups

<dc-chart width="500" height="350">
  <dc-scatter label="Control" fill="#2563eb">
    <dc-point x="5" value="12"></dc-point>
    ...
  </dc-scatter>
  <dc-scatter label="Treated" fill="#dc2626"
              shape="triangle">
    <dc-point x="5" value="28"></dc-point>
    ...
  </dc-scatter>
  <dc-legend position="bottom"></dc-legend>
</dc-chart>

Series are dimensionless in the legend: a cloud of readings has no single aggregate value, so none is invented.

Naming the Axes

A scatter's axes both mean something, and neither is self-describing the way a category label is. Titles are worth the two lines. Everything <dc-axis> already does applies — min-value, max-value, tick-interval, value-format and the rest.

Titles and Formats

<dc-chart width="500" height="350">
  <dc-axis position="bottom" value-format="number 0">
    <dc-title>Dose (mg)</dc-title>
  </dc-axis>
  <dc-axis position="left" value-format="number 0">
    <dc-title>Response</dc-title>
  </dc-axis>
  <dc-scatter label="Readings">...</dc-scatter>
</dc-chart>
Dose (mg) Response

A Fixed Domain

<dc-axis position="bottom" type="value"
         min-value="0" max-value="50"
         tick-interval="10"
         value-format="number 0">
  <dc-title>Dose (mg)</dc-title>
</dc-axis>
Dose (mg) Response

Left to itself the domain rounds outward to whole ticks, so the extreme readings sit inside the plot rather than straddling the axis lines.

Marker Shape, Size and Opacity

shape takes the same vocabulary as point-shape on a line. size is the marker radius in viewBox units. fill-opacity earns its keep when the cloud is dense: overlapping translucent markers show where the readings pile up, which opaque ones hide.

Shapes per Series

<dc-scatter label="Site A" shape="circle">...</dc-scatter>
<dc-scatter label="Site B" shape="square">...</dc-scatter>
<dc-scatter label="Site C" shape="diamond">...</dc-scatter>

Dense Cloud

<dc-scatter label="Samples" size="7"
            fill-opacity="0.35">
  <dc-point x="10" value="22"></dc-point>
  <dc-point x="11" value="24"></dc-point>
  ...
</dc-scatter>

With a Trend Line

Scatter markers are drawn above areas and beneath lines, so a <dc-line> over the same chart lies on top of the cloud. The line places its points by category rather than by x, so give it points that span the plot.

Cloud and Fit

<dc-chart width="500" height="350">
  <dc-scatter label="Readings" fill-opacity="0.6">
    ...
  </dc-scatter>
  <dc-line label="Trend" stroke="#dc2626"
           show-value="false">
    <dc-point value="14"></dc-point>
    <dc-point value="52"></dc-point>
  </dc-line>
  <dc-legend position="bottom"></dc-legend>
</dc-chart>

Popups and Links

<dc-scatter label="Readings" auto-popup>
  <dc-point x="5" value="12" href="/sample/1"></dc-point>
  ...
</dc-scatter>

Hover a marker: the popup names both coordinates, because a scatter point means nothing without its x. Tab into the chart and the same information is announced, along with the correlation for each series.
