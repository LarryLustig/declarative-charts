Color Priority

Colors are resolved in this priority order:

  1. Element-level - fill or stroke on individual elements
  2. Palette value match - min-value/max-value from a palette
  3. Palette label match - label match from a palette
  4. Chart-level colors - fill-colors, gradients, etc.
  5. Auto-generated - Algorithmic color generation

For reusable color definitions that can be shared across charts and used outside charts (e.g., in tables or prose), see Palettes.
