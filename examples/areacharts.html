Area Charts

Display filled regions bounded by data points using <dc-area> and <dc-point> elements

Basic Area Charts

Area charts show filled regions under a line. Use <dc-area> elements containing <dc-point> elements. The area extends from the data points down to the zero line.

Single Area

<dc-chart width="500" height="350">
  <dc-title>Website Traffic</dc-title>
  <dc-area fill="#4CAF50" label="Visitors">
    <dc-point value="100" label="Mon"></dc-point>
    <dc-point value="150" label="Tue"></dc-point>
    <dc-point value="180" label="Wed"></dc-point>
    <dc-point value="140" label="Thu"></dc-point>
    <dc-point value="200" label="Fri"></dc-point>
  </dc-area>
</dc-chart>
Website Traffic

Stacked Area Charts

When multiple areas are present, they stack by default. Each area's baseline is the cumulative sum of previous areas. This is useful for showing part-to-whole relationships over time.

Curve Fitting

Use the curve-fit attribute to control how lines are drawn between points. The same options are available as for line charts.

Smooth Curves

<dc-chart width="500" height="350">
  <dc-title>Smooth Area</dc-title>

           label="Sales">
