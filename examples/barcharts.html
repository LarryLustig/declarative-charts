Bar Chart Basics

Simple bar charts with different orientations and styles

Orientation

Use the orientation attribute to control bar direction:

  • vertical (default) - Bars grow upward from the bottom
  • horizontal - Bars grow rightward from the left
  • vertical-reverse - Bars grow downward from the top
  • horizontal-reverse - Bars grow leftward from the right

Vertical (Default)

Default Colors

Use bar-color on the chart to set a default fill color for all bars, or use palette for automatic color assignment:

Using bar-color

<dc-chart width="500" height="350" bar-color="#9C27B0">
  <dc-title>Single Color Theme</dc-title>
  <dc-bar value="30" label="Q1"></dc-bar>
  <dc-bar value="50" label="Q2"></dc-bar>
  <dc-bar value="40" label="Q3"></dc-bar>
  <dc-bar value="60" label="Q4"></dc-bar>
</dc-chart>
