Bar Chart Examples

All bar chart variants and configurations

Basic Bar Charts

Simple bar charts with different orientations. Use the orientation attribute to control bar direction:

  • vertical (default) - Bars grow upward from the bottom
  • horizontal - Bars grow rightward from the left
  • vertical-reverse - Bars grow downward from the top
  • horizontal-reverse - Bars grow leftward from the right

Grouped Bar Charts

Stacked Bar Charts

Break a bar into segments using <dc-bar-segment> elements inside a <dc-bar>. Each segment has its own value and label. Colors are automatically assigned based on segment labels — all segments with the same label get the same color, ensuring visual consistency. The legend displays segment labels (not bar labels) for stacked charts.

Negative Values

Bars automatically extend downward (or leftward for horizontal) for negative values. A zero line appears when the range spans both positive and negative values. Use palettes with min-value and max-value to style positive and negative bars differently.

  <dc-bar value="75" label="Q3"></dc-bar>

</dc-chart>
