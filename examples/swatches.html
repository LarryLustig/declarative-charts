Swatches

Use <dc-swatch> to display palette colors outside of charts, creating visual associations in prose and tables.

Swatches in Prose

Swatches can be used inline with text to create visual associations between chart colors and written content:

Inline Color References

<p>
  <dc-swatch palette="brand-colors" label="Revenue"></dc-swatch>
  Revenue increased 15% this quarter.
</p>
<p>
  <dc-swatch palette="brand-colors" label="Expenses"></dc-swatch>
  Expenses were held flat.
</p>
<p>
  <dc-swatch palette="brand-colors" label="Profit"></dc-swatch>
  Profit margins improved significantly.
</p>

Revenue increased 15% this quarter.

Expenses were held flat.

Profit margins improved significantly.

Swatch Shapes

Use the shape attribute to change the swatch appearance. Standard shapes include: circle, square, rect, line, triangle, diamond, star, cross, plus. You can also use Unicode characters.

Standard Shapes

<dc-swatch palette="department-colors" label="Engineering" shape="circle"></dc-swatch>
<dc-swatch palette="department-colors" label="Marketing" shape="square"></dc-swatch>
<dc-swatch palette="department-colors" label="Sales" shape="triangle"></dc-swatch>
<dc-swatch palette="department-colors" label="Operations" shape="diamond"></dc-swatch>
Circle Square Triangle Diamond
Star Cross Plus Line

Unicode Characters

<dc-swatch palette="brand-colors" label="Revenue" shape="★"></dc-swatch>
<dc-swatch palette="brand-colors" label="Expenses" shape="⚠"></dc-swatch>
<dc-swatch palette="brand-colors" label="Profit" shape="✓"></dc-swatch>
Star Warning Checkmark
Filled circle Filled square Triangle up

Note: CSS color only works for monochrome Unicode symbols. Color emojis (like 📈) ignore the palette color.

Line Chart Swatches

Use swatches with the line shape to match line chart legends:

Line Shape Swatches

<dc-swatch palette="brand-colors" label="Revenue" shape="line"></dc-swatch>
Revenue shows strong upward trend

<dc-swatch palette="brand-colors" label="Expenses" shape="line"></dc-swatch>
Expenses remain stable

Revenue shows strong upward trend

Expenses remain stable

Matching Chart

<dc-chart palette="brand-colors" width="500" height="300">
  <dc-title>Quarterly Trends</dc-title>
  <dc-line label="Revenue">
    <dc-point value="100" label="Q1"></dc-point>
    <dc-point value="120" label="Q2"></dc-point>
  </dc-line>
  <dc-line label="Expenses">
    <dc-point value="80" label="Q1"></dc-point>
    <dc-point value="85" label="Q2"></dc-point>
  </dc-line>
</dc-chart>

Swatch with Built-in Palettes

Swatches can also reference built-in palettes by index (0-based) using the index attribute:

Index-Based Colors

<dc-swatch palette="category10" index="0"></dc-swatch> First color
<dc-swatch palette="category10" index="1"></dc-swatch> Second color
<dc-swatch palette="category10" index="2"></dc-swatch> Third color
