Logging & Debug Console

The logging system captures internal calculations during chart rendering, helping you understand how values are derived and debug layout issues.

Basic Usage

Add logging="info" to any chart to enable log capture, then use <dc-log-console> with a CSS selector to display the logs.

Bar Chart with Logging

<dc-chart id="bar-demo" logging="info" width="500" height="350">
  <dc-title>Sales by Quarter</dc-title>
  <dc-bar value="30" label="Q1"></dc-bar>
  <dc-bar value="45" label="Q2"></dc-bar>
  <dc-bar value="25" label="Q3"></dc-bar>
  <dc-bar value="50" label="Q4"></dc-bar>
</dc-chart>

<dc-log-console chart="#bar-demo"></dc-log-console>
Sales by Quarter

Log Levels

The logging attribute controls which messages are captured:

  • logging="false" - No logging (default, best performance)
  • logging="error" - Only errors
  • logging="warning" - Warnings and errors
  • logging="info" or logging="true" - All messages

  <dc-pie-slice value="30" label="B"></dc-pie-slice>
</dc-pie-chart>

<dc-log-console chart="#warning-demo"></dc-log-console>

Browser Console Output

Use the console-log attribute to echo log messages to the browser's developer console. This is useful for debugging without adding a <dc-log-console> element.

Echo Warnings to Console

<dc-chart id="console-demo" logging="info" console-log="warning" width="500" height="350">
  <dc-title>Chart with Issues</dc-title>
  <dc-bar value="30" label="Normal"></dc-bar>
  <dc-bar value="0" label="Zero Value"></dc-bar>
  <dc-line label="Empty Line">
    <!-- No points - will trigger warning -->
  </dc-line>
</dc-chart>
Chart with Issues

Open your browser's DevTools console to see warnings about the zero-value bar and empty line.

Console Log Levels

The console-log attribute controls which messages are echoed to the browser console:

  • console-log="none" - No console output (default)
  • console-log="error" - Errors → console.error()
  • console-log="warning" - Warnings → console.warn(), Errors → console.error()
  • console-log="info" - All messages → console.log() / warn() / error()

Note: Messages must first pass the logging level filter before the console-log filter is applied. Set logging="info" to capture all messages, then use console-log to control which appear in DevTools.

Console Grouping

Messages from each render cycle are grouped under a collapsible header in the console. Charts are identified by:

  1. ID attribute: dc-chart#console-demo render
  2. Title text: dc-chart "Chart with Issues" render
  3. Tag name only: dc-chart render (if no id or title)

This makes it easy to identify which chart generated each group of messages, especially when multiple charts are on the page.

What Issues Are Detected

  • Empty charts - No data elements, or all elements hidden
  • Zero/negative values - Bars or slices that won't be visible
  • Lines without points - <dc-line> with no <dc-point> children
  • Small pie slices - Slices under 3% that are hard to see or click
  • Invalid donut radius - inner-radius values that break rendering
  • Uniform colors - All elements have the same color (possible config issue)
  • Increasing funnel values - Later stages larger than earlier (unusual pattern)

What Gets Logged

The logging system captures calculations including:

  • Padding calculations - How padding values are derived from attributes, legends, and axis labels
  • Color resolution - Which color mode was used (gradient, palette, auto) and any overrides
  • Legend dimensions - Calculated width, height, layout type, and column count
  • Axis label padding - Space allocated for Y-axis values and X-axis labels
  • Data summaries - Element counts, max values, totals
  • Per-element details - Individual bar/slice/stage positions, sizes, and percentages
  • Chart-specific calculations - Bar unit dimensions, funnel segment heights, chevron parsing, etc.
