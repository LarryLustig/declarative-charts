Custom Palettes

Define reusable color schemes with <dc-palette> that can be shared across multiple charts and used outside of charts with <dc-swatch>. Custom palettes support label matching and value-range matching for conditional coloring.

For built-in palettes (categorical, sequential, diverging), gradients, and inline color options, see Colors.

Basic Label-Based Palettes

Define a palette with <dc-palette> and <dc-fill> elements, then reference it from charts using the palette attribute:

Bar Chart with Palette

<dc-palette id="brand-colors">
  <dc-fill label="Revenue" fill="#2563eb"></dc-fill>
  <dc-fill label="Expenses" fill="#dc2626"></dc-fill>
  <dc-fill label="Profit" fill="#16a34a"></dc-fill>
</dc-palette>

<dc-chart palette="brand-colors" width="500" height="350">
  <dc-title>Q4 Financial Summary</dc-title>
  <dc-bar value="120" label="Revenue"></dc-bar>
  <dc-bar value="80" label="Expenses"></dc-bar>
  <dc-bar value="40" label="Profit"></dc-bar>
  <dc-legend></dc-legend>
</dc-chart>
Q4 Financial Summary

Pie Chart with Same Palette

<dc-chart palette="brand-colors" width="500" height="350">
  <dc-title>Q4 Breakdown</dc-title>
  <dc-slice value="120" label="Revenue"></dc-slice>
  <dc-slice value="80" label="Expenses"></dc-slice>
  <dc-slice value="40" label="Profit"></dc-slice>
  <dc-legend position="right"></dc-legend>
</dc-chart>

Value-Range Palettes

Use min-value and max-value to define color thresholds based on numeric values:

Performance Thresholds

<dc-palette id="performance-thresholds">
  <dc-fill max-value="30" fill="#fee2e2"></dc-fill>
  <dc-fill min-value="30" max-value="70" fill="#fef3c7"></dc-fill>
  <dc-fill min-value="70" fill="#dcfce7"></dc-fill>
</dc-palette>

<dc-chart palette="performance-thresholds" width="500" height="350">
  <dc-title>Team Performance Scores</dc-title>
  <dc-bar value="25" label="Team A"></dc-bar>
  <dc-bar value="55" label="Team B"></dc-bar>
  <dc-bar value="85" label="Team C"></dc-bar>
  <dc-bar value="42" label="Team D"></dc-bar>
</dc-chart>
Team Performance Scores

How Value Matching Works

Value ranges are checked in DOM order. The first matching range wins:

  • Team A (25): Matches max-value="30" → Light red (low)
  • Team B (55): Matches min="30" max="70" → Yellow (medium)
  • Team C (85): Matches min-value="70" → Light green (high)
  • Team D (42): Matches min="30" max="70" → Yellow (medium)

Priority: Value matching takes precedence over label matching, allowing you to override colors based on thresholds.

Positive/Negative Value Palettes

A common use case for value-range palettes is coloring positive values one color and negative values another:

Profit/Loss Bars

<dc-palette id="pos-neg">
  <dc-fill max-value="0" fill="#F44336"></dc-fill>
  <dc-fill min-value="0" fill="#4CAF50"></dc-fill>
</dc-palette>

<dc-chart palette="pos-neg" width="500" height="350">
  <dc-title>Monthly Profit/Loss</dc-title>
  <dc-bar value="35" label="Jan"></dc-bar>
  <dc-bar value="-20" label="Feb"></dc-bar>
  <dc-bar value="50" label="Mar"></dc-bar>
  <dc-bar value="-10" label="Apr"></dc-bar>
  <dc-bar value="25" label="May"></dc-bar>
  <dc-bar value="-30" label="Jun"></dc-bar>
</dc-chart>
Monthly Profit/Loss

How It Works

The palette uses two <dc-fill> rules with value boundaries at zero:

  • max-value="0" matches any value ≤ 0 (negative values)
  • min-value="0" matches any value ≥ 0 (positive values)

When a bar has a negative value, it matches the first rule and gets red. When positive, it matches the second rule and gets green.

This same palette works for any chart type that supports negative values, including line charts (point fills) and bubble charts.

Swatches for External Use

Use <dc-swatch> to display palette colors outside of charts, creating visual associations in prose and tables:

Swatches in Prose

<p>
  <dc-swatch palette="brand-colors" label="Revenue"></dc-swatch>
  Revenue increased 15% this quarter.
</p>
<p>
  <dc-swatch palette="brand-colors" label="Expenses"></dc-swatch>
  Expenses were held flat.
</p>
<p>
  <dc-swatch palette="brand-colors" label="Profit"></dc-swatch>
  Profit margins improved significantly.
</p>

Swatch Shapes

Use the shape attribute to change the swatch appearance. Standard shapes include: circle, square, rect, line, triangle, diamond, star, cross, plus. You can also use Unicode characters.

Standard Shapes

<dc-swatch palette="department-colors" label="Engineering" shape="circle"></dc-swatch>
<dc-swatch palette="department-colors" label="Marketing" shape="square"></dc-swatch>
<dc-swatch palette="department-colors" label="Sales" shape="triangle"></dc-swatch>
<dc-swatch palette="department-colors" label="Operations" shape="diamond"></dc-swatch>

Unicode Characters

<dc-swatch palette="brand-colors" label="Revenue" shape="★"></dc-swatch>
<dc-swatch palette="brand-colors" label="Expenses" shape="⚠"></dc-swatch>
<dc-swatch palette="brand-colors" label="Profit" shape="✓"></dc-swatch>

Note: CSS color only works for monochrome Unicode symbols. Color emojis (like 📈) ignore the palette color.

Line Charts with Palettes

Line charts use the palette's stroke attribute for line colors:

Multi-Line Chart

<dc-palette id="brand-colors">
  <dc-fill label="Revenue" fill="#2563eb" stroke="#2563eb"></dc-fill>
  <dc-fill label="Expenses" fill="#dc2626" stroke="#dc2626"></dc-fill>
</dc-palette>

<dc-chart palette="brand-colors" width="500" height="350">
  <dc-title>Quarterly Trends</dc-title>
  <dc-line label="Revenue">
    <dc-point value="100" label="Q1"></dc-point>
    <dc-point value="120" label="Q2"></dc-point>
    <dc-point value="115" label="Q3"></dc-point>
    <dc-point value="140" label="Q4"></dc-point>
  </dc-line>
  <dc-line label="Expenses">
    <dc-point value="80" label="Q1"></dc-point>
    <dc-point value="85" label="Q2"></dc-point>
    <dc-point value="90" label="Q3"></dc-point>
    <dc-point value="88" label="Q4"></dc-point>
  </dc-line>
  <dc-legend position="top"></dc-legend>
</dc-chart>

Explicit Overrides

Element-level fill and stroke attributes always take precedence over palette colors:

Override Individual Elements

<dc-chart palette="brand-colors" width="500" height="350">
  <dc-bar value="120" label="Revenue"></dc-bar>
  <dc-bar value="80" label="Expenses" fill="purple"></dc-bar>
  <dc-bar value="40" label="Profit"></dc-bar>
</dc-chart>
Override Example

Priority Order

Colors are resolved in this priority order:

  1. Element's own fill/stroke (highest priority)
  2. Custom palette value range match (min-value/max-value)
  3. Custom palette label match
  4. Chart-level color settings (built-in palettes, gradients, color lists)
  5. Auto-generated colors (lowest priority)

See Colors: Color Priority for a detailed example.
