Basic Combo Charts

Combine bars showing actual values with a line showing trends or targets.

Color conventions in these examples: When all bars represent the same data series (e.g., monthly revenue), they share a single color. When bars show performance against a target, colors indicate status: green = above target, orange = near target, red = below target.
